# E-Commerce Business Performance Analysis (SQL)

## Project Overview
This project analyzes e-commerce sales data using SQL to uncover
revenue trends, customer behavior, delivery performance and
payment preferences.

## Business Objectives
- Analyze monthly revenue trends
- Identify top selling products
- Understand customer purchasing patterns
- Evaluate delivery performance
- Analyze payment methods

## Dataset
Source: Kaggle – Brazilian E-commerce Dataset  
Tables:
- orders
- customers
- order_items
- products
- payments
- reviews

## Tools Used
- MySQL
- SQL (Joins, CTEs, Window functions)


## Key Analysis
- Monthly revenue trend
- Top products by revenue
- Late delivery impact
- City wise order distribution
- Payment preference analysis

## Key Insights
✔ November-December shows highest sales  
✔ Credit card dominates payments  
✔ Late deliveries lead to poor ratings  
✔ Top 10 products contribute major revenue  

## Project Files
- sql_queries.sql – all queries
- dataset folder – raw csv files
